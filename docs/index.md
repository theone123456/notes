# 欢迎来到我的学习笔记

个人学习知识库，内容由本地笔记仓库自动同步，网站自动构建部署。

## 笔记分类

分类与目录导航见左侧边栏，由同步脚本自动生成：

- **AI Agent 开发学习** -- LLM / Agent 学习计划、每日任务与练习代码
- **pytest 中文文档** -- pytest 使用教程与示例代码

## 同步机制

- 笔记源目录在 `sync_config.json` 中配置，新增路径只需追加一项
- `*.md` 直接渲染；`*.py` 等代码文件自动转换为带语法高亮的 Markdown 页面
- 同步时自动排除 `.env` 等敏感文件，并对内容中疑似密钥（API Key、Token 等）自动脱敏
