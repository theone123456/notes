# Day 13 学习笔记：概念查漏

> 核心命题：训练三阶段塑造模型的全部行为——预训练给能力，微调教对话，对齐定偏好；API 层面观察到的现象，根子都在训练阶段

## 训练三阶段：预训练 / 微调 / 对齐

> 来源：LLM 基础概念 · 目的：扫尾阶段 0 最后一块【了解】级知识；三阶段是 Step 4"现象连线"的坐标系

### 预训练：知识从哪来

**预训练（pre-training）**：在海量文本上训练模型只做一件事——**给定上文，预测下一个 token 的概率分布**（next token prediction）。处理单位：token。

**为什么"只管接龙"能顺便学到知识**：为了把预测这一件事做好，模型被迫理解上下文，知识和能力都是副产品。

```text
训练目标：预测下一个 token（唯一目标）
  ↓
要预测得准，必须理解：
  语法（词怎么接）· 事实（"法国的首都"后面通常接"巴黎"）
  逻辑（论证怎么展开）· 文体结构（试卷一问接一问、对话一问一答）
  ↓
知识、语法、推理模式 = "把接龙做好"的副产品
```

关键：模型对语义的理解恰恰是预训练最值钱的部分——否则续写不可能连贯，后续的微调和 RAG 也无从谈起。

**base model：会接龙，不会对话**。预训练的产物是 base model（基座模型）——一台只会续写的机器：

```text
问 base model："法国的首都是哪里？"
  ↓
它眼中：这不是"问题"，是一段待续写的文本开头
  ↓
训练数据里试卷 / FAQ / 访谈大量是"一问接一问"的形态
  ↓
高概率续写："德国的首都是哪里？意大利的首都是哪里？"（而非回答"巴黎"）
```

初答曾把原因归为"base model 不理解输入的语义"——这是误区，正解是**训练目标决定行为**：

| 误区 | 正解 |
|---|---|
| 它不理解语义，所以不会对话 | 它对语义的理解正是续写连贯的前提，是最值钱的部分 |
| 不会对话是能力问题（它做不到） | 是训练目标问题（没人教过）：预训练只见过连续文本，从未见过"指令 → 回答"配对；缺的不是理解，是"有人教过它：输入是要满足的指令，不是要续写的开头" |

它缺的这一课，正是 Step 2 微调（SFT）要补的环节。

**量级直觉：为什么是大厂的游戏**：

| 维度 | 量级 | 直觉 |
|---|---|---|
| 数据 | TB 级文本，几万亿 token | 把全网优质文本读几遍 |
| 算力 | 上千张 GPU 跑数月 | 仅电费就是百万美元级 |
| 成本 | 单次训练千万美元级 | 重跑一次 = 烧掉一轮融资 |

且**能力随规模增长**（scaling）：小规模预训练不出同等能力，没有"缩小版省钱"的捷径。推论：个人和小厂的正确姿势是**从现成模型起步**（微调 / 提示词 / RAG）——这正是 Step 2 和阶段 3 存在的意义。

**关键认知**：

1. **预训练目标唯一且简单**：给定上文预测下一个 token 的概率分布，处理单位是 token——Day 5 的 temperature 正是作用在这个分布上
2. **知识是接龙的副产品**：为了预测得准，模型被迫理解语法、事实、逻辑——不是"不理解语义"，恰恰相反
3. **base model 会接龙不会对话**：原因是训练目标（只学过续写、没学过应答），不是理解能力缺失；问题在它眼里只是"待续写的开头"
4. **量级决定玩家**：TB 数据 + 千卡数月 + 千万美元级单次成本，能力随规模涌现、无廉价捷径——个人/小厂从现成模型起步

> 一句话：预训练用"预测下一个 token"这一件事逼出了全部能力，但也把模型定格成一台只会续写的机器。

### 微调（SFT）：从会接龙到会对话

**监督微调 SFT（Supervised Fine-Tuning）**：用人工标注的"指令 → 高质量回答"示范对继续训练 base model，教它**按指令回答**而不是续写。

**SFT 和预训练差在哪**：不换机制，换数据分布。

| 维度 | 预训练 | SFT |
|---|---|---|
| 数据形态 | 连续文本流（书籍/文章/网页/代码，无结构） | 指令→回答配对（有结构） |
| 监督信号 | 无标注，自监督 | 人工写的高质量示范 |
| 量级 | 万亿 token | 万~百万级样本（差 4-6 个数量级） |
| 教会模型 | 语言与世界的规律 | 输入的角色：是"待满足的指令" |

**SFT 前后的行为变化**（同一输入，模型眼里的角色变了）：

```text
输入："写一首关于秋天的诗"

base model：这是一段待续写的开头
  → 高概率续写："写一首关于冬天的诗。写一首关于月亮的散文。"（示范更多指令）

SFT 后：这是一个待满足的指令
  → 高概率续写：真的输出一首关于秋天的诗
```

机制仍是预测下一个 token，只是见了几十万条"指令后面跟着高质量回答"的示范后，"指令 → 应答"成了高概率路径。**微调不改机制，改的是输入在模型眼里的角色**。

**手段选择的成本阶梯**（改行为 vs 补知识是两条正交的线）：

```text
改行为：提示词（最便宜，即改即生效、无需重训）
          ↓ 约束复杂 / 提示词太长不稳定 / 成本高
        微调（重武器：稳定但贵）
补知识：RAG（与上面正交，常组合使用）
```

| 需求 | 归属 | 手段 |
|---|---|---|
| 客服机器人固定话术 + 固定 JSON 格式 | 改行为（约束复杂且要稳定） | 微调（轻量场景提示词 + JSON mode 可顶） |
| 医疗 / 法律助手要稳定的领域术语和口吻 | 改行为（领域风格，提示词难写稳） | 微调 |
| 回答公司内部产品手册的专业知识 | 补知识（且会更新） | RAG（微调灌知识 = 每次更新都要重训） |
| 回答更啰嗦、爱举例 | 改行为（风格偏好） | 提示词（一句话的事） |

**量级与 LoRA**：个人玩得起微调、玩不起预训练，差距 4-6 个数量级。

| 方式 | 更新范围 | 资源 | 成本量级 |
|---|---|---|---|
| 预训练 | 从零开始，全部参数 | 万亿 token 数据 + 千卡数月 | 千万美元级 |
| 全参微调 | 所有参数 + 优化器状态 | 多卡集群数天~数周 | 千~万美元级 |
| LoRA | 冻结原模型，只训插入的低秩小矩阵（约 0.1%-1% 参数） | 单张消费级显卡数小时~数天 | 几十~几百美元 |

LoRA 思想：改行为不需要动全部知识——好比不重写整本书，只在页边贴批注。

**关键认知**：

1. **SFT 的数据形态是"指令→回答"示范对**：与预训练的差别在数据（结构化配对、人工标注、量级小 4-6 个数量级），不在机制（仍是预测下一个 token）
2. **SFT 改变的是"输入的角色"**：从"待续写的开头"变成"待满足的指令"——base model 会接龙不会对话的那一课，SFT 补上了
3. **改行为与补知识是正交的两条线**：改行为走成本阶梯（提示词 → 微调），补知识用 RAG；能用提示词解决的不微调
4. **量级决定玩法**：预训练千万美元 / 全参微调千~万美元 / LoRA 几十~几百美元——个人开发者从现成模型起步，微调（尤其 LoRA）是够得着的那一档

> 一句话：SFT 用示范教会模型"把输入当指令"，但手段选择先看成本阶梯——提示词能解决的事，不劳微调。

### 对齐：回答得更好、更安全

**对齐（alignment）**：SFT 后模型"会回答"，但回答未必符合人类偏好——可能啰嗦、有害、不诚实。对齐用人类的偏好判断继续优化，让模型变得好用、安全、有分寸。

**SFT 教不会什么**：示范是单点，偏好是比较级。

- SFT 的 loss 只要求"贴近这一份示范"，没有任何"比别的回答更好"的比较信号——一份再好的示范，也告诉不了模型"好在哪、比谁好"
- 精确化：SFT 数据里放拒答示范也能教一部分拒答；真正的差别是**分寸**——什么时候该拒、答到什么程度、啰嗦还是克制，这类偏好判断示范给不出来

| | SFT | 对齐 |
|---|---|---|
| 回答的问题 | 怎么答 | 哪个更好 |
| 学习方式 | 模仿示范（单点） | 优化偏好（比较级） |
| 训练信号 | "贴近这份示范" | "人类觉得这个比那个好" |

**RLHF（人类反馈强化学习）三步**（了解级，不碰数学）：

| 步骤 | 做什么 | 解决什么 |
|---|---|---|
| ① 偏好数据 | 同一问题采样多个回答，人类排序 | 把"更好"的判断收集起来（量有限） |
| ② 奖励模型（RM） | 用排序数据训练一个打分器 | **把人类品味装进小模型**，可无限给新输出打分——规模化的关键一环 |
| ③ 强化学习 | 主模型在 RL 循环里最大化 RM 打分 | 往"人类会觉得更好"的方向优化 |

标注员不可能永远在线打分，RM 就是"人类偏好的规模化替身"。DPO 等变体知道名字即可，不深入。

**对齐的痕迹**（日常使用中的观察）：拒答有害请求、语气客气爱分点、加免责声明、"作为 AI 助手我没有……"——这些都是预训练和 SFT 给不出的姿态。

回看 Day 6 实验的两个混合归因案例：

| 现象 | 归因分解 | 主导 |
|---|---|---|
| 纠正用户错误前提（虚构实体实验） | 预训练先验（知道真相）+ 对齐成分（宁可纠正也不顺着用户） | 先验（无 system prompt 也纠正了） |
| 冷门知识不编造（返回空） | 推理能力（判断得出）+ 对齐偏好（选择不说） | 两者共存；理想表现是明确说"我不知道"而非返回空 |

**三阶段总结**（Step 1-3 收口）：

| 阶段 | 解决的问题 | 数据 | 机制 | 产物 |
|---|---|---|---|---|
| 预训练 | 能力：语言与世界的规律 | 万亿 token 连续文本（无标注） | 预测下一个 token | base model（会接龙不会对话） |
| SFT 微调 | 对话：把输入当指令 | 万~百万级"指令→回答"示范 | 仍是预测下一个 token，换数据分布 | 会应答的 chat model |
| 对齐 | 偏好：哪个回答更好、更安全 | 人类排序 → 奖励模型 | 强化学习最大化 RM 打分 | 好用、安全、有分寸的助手 |

**关键认知**：

1. **对齐解决 SFT 解决不了的问题**：偏好是比较级、示范是单点——SFT 的 loss 里没有"比别的回答更好"的信号，"分寸"只能从比较中来
2. **RLHF 三步**：偏好数据（人类排序）→ 奖励模型（把人类品味装进小模型，规模化的关键）→ 强化学习（往高分优化）
3. **SFT vs 对齐 = 模仿示范 vs 优化偏好**（面试常考）：SFT 回答"怎么答"，对齐回答"哪个更好"
4. **归因要小心混合情况**：日常行为往往是多个阶段的产物叠加（先验 + 诚实偏好、推理 + 弃答偏好），判断主导因素要有证据（如消融实验的思路）

> 一句话：预训练给能力，SFT 教对话，对齐定偏好——一条流水线把"概率接龙机器"改造成"有分寸的助手"。

### 现象连线：API 行为 ← 训练阶段

**归因口诀**：先问"这是机器的属性，还是训练出的行为"——属性多归预训练，行为归 SFT + 对齐。

| 现象（出处） | 归属阶段 | 一句话解释 |
|---|---|---|
| system prompt 能改变行为（Day 2/3） | SFT + 对齐 | 角色体系是 SFT 数据格式教的约定，可靠服从是对齐强化的；base model 没有角色概念，messages 对它只是待续写的文本 |
| 幻觉不可避免（Day 6） | 预训练 | 根因是概率预测没有事实校验环节，数据不包含 / 误导 / 截止都是下游成因 |
| temperature 调整有效（Day 5） | 预训练 | 词表上的概率分布是"预测下一个 token"目标的直接产物；对齐只调分布形状，不创造分布（base model 照样能调） |
| 知识有截止时间（Day 6） | 预训练 | SFT/对齐捎带的知识量级差 4-6 个数量级，主体知识定格在预训练截止点 |
| 模型拒答有害请求 | SFT + 对齐 | SFT 给拒答示范，对齐定分寸；预训练"知道什么有害"，缺的是"识别后拒答"的行为模式 |
| 上下文窗口上限、按 token 计费（Day 4） | 预训练（架构） | 机器的物理属性：token 是处理单位（计费依据），注意力开销随长度平方涨 + 训练时最大序列长度（硬上限依据） |

**前瞻连线**（今天埋的线，阶段 1-3 兑现）：

| 后续要学的 | 连回今天的哪条线 |
|---|---|
| RAG 缓解幻觉（阶段 3） | 打在"预训练知识定格"的软肋上：用检索补"训练后世界的变化"——Day 6 实验已证明提示词约束对此无效（模型不知道自己过时） |
| Function Calling（阶段 1） | 依赖"指令遵循"的地基（SFT 建立、对齐强化）：模型要能可靠地按格式表达"我要调工具"，是"把输入当指令"能力的延伸 |

**关键认知**：

1. **归因口诀**：API 层的现象先分"机器的属性 vs 训练出的行为"——属性归预训练（分布 / 知识 / 窗口 / 计费），行为归 SFT + 对齐（角色服从 / 应答 / 拒答 / 分寸）
2. **区分"分布的存在"与"分布的形状"**：temperature 有效记在预训练头上（分布是目标的直接产物），对齐只能调形状——本日曾在"多候选打分"与"推理期解码"上误归因
3. **两条前瞻线**：RAG 打"知识定格"，Function Calling 靠"指令遵循"——阶段 1 和阶段 3 会分别兑现

> 一句话：预训练决定机器是什么，SFT 和对齐决定机器怎么表现——API 层的每个现象都能沿这条线找到根。

顺带三个观察：

1. **问题本身是幻觉探针**：问实时天气，模型答"无法获取实时信息"没编造时段——Day 6"知道自己不知道"的又一次验证
