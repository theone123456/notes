> Python 中的**列表**和**元组**都是用于存储数据序列的内置数据结构，它们在很多方面非常相似，但存在一个根本性的区别：**列表是可变的，而元组是不可变的。**
>
> 下面从几个核心维度详细解释它们的区别：
>
> ### 1. 可变性
> 这是列表和元组最本质的区别。
> *   **列表**：创建后，你可以随时修改、添加或删除其中的元素。
> *   **元组**：创建后，其内容和大小就被固定，不能进行任何修改、添加或删除操作。
>
> ```python
> # 列表：可变
> my_list = [1, 2, 3]
> my_list[0] = 99      # 合法：修改元素
> my_list.append(4)    # 合法：添加元素
> print(my_list)       # 输出: [99, 2, 3, 4]
>
> # 元组：不可变
> my_tuple = (1, 2, 3)
> my_tuple[0] = 99      # 报错：TypeError: 'tuple' object does not support item assignment
> my_tuple.append(4)   # 报错：AttributeError: 'tuple' object has no attribute 'append'
> ```
>
> > **注意（元组的"伪可变"陷阱）：** 如果元组内部包含了一个可变对象（如列表），这个内部的可变对象是可以被修改的。但这并没有打破元组的不可变性，因为元组内部存储的仅仅是那个列表的内存地址，地址没有变。
> > ```python
> > tuple_with_list = (1, 2, [3, 4])
> > tuple_with_list[2][0] = 'changed' # 合法
> > print(tuple_with_list)            # 输出: (1, 2, ['changed', 4])
> > ```
>
> ### 2. 语法表示
> *   **列表**：使用方括号 `[]` 包裹元素。
> *   **元组**：通常使用圆括号 `()` 包裹元素。
>
> ```python
> my_list = [1, 2, 3]
> my_tuple = (1, 2, 3)
> ```
>
> > **特例：** 创建单元素元组时，必须在这个元素后面加一个逗号，否则 Python 会将其视为普通变量（括号被当作数学运算中的改变优先级的符号）。
> > ```python
> > not_a_tuple = (1)    # 这只是数字 1，类型为 int
> > a_tuple = (1,)       # 这才是一个元组，类型为 tuple
> > ```
>
> ### 3. 方法和函数
> 因为列表需要支持修改操作，它内置了非常多的方法，如 `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `clear()`, `sort()`, `reverse()` 等。
> 而元组由于不可变，只有两个公开方法：
> *   `count()`：统计某个元素出现的次数。
> *   `index()`：查找某个元素的索引位置。
>
> ### 4. 作为字典的键
> *   **列表**：不能作为字典的键，也不能作为集合的元素。因为列表可变，其哈希值会随时改变，Python 会抛出 `TypeError: unhashable type: 'list'`。
> *   **元组**：如果元组内部只包含不可变元素（如数字、字符串、其他纯元组），那么它**可以作为字典的键**或放入集合中。
>
> ```python
> # 列表做键会报错
> # my_dict = {[1, 2]: "value"} # TypeError
>
> # 元组做键合法
> my_dict = {(1, 2): "value"}
> print(my_dict[(1, 2)]) #

> Python 中的**列表**和**元组**都是用于存储一组有序数据的数据结构（序列类型），它们在很多操作上非常相似（如索引、切片、迭代等），但它们之间有几个本质的区别。
>
> 以下是 Python 列表和元组的详细区别：
>
> ### 1. 可变性-- 最核心的区别
> *   **列表是可变的：** 创建列表后，你可以随意修改它的内容，包括添加、删除或更改元素。
> *   **元组是不可变的：** 元组一旦创建，其内容就不能再被修改。你不能添加、删除或替换其中的元素。
>
> **代码示例：**
>
> ```python
> # 列表：可变
> my_list = [1, 2, 3]
> my_list[0] = 10      # 修改元素 -> [10, 2, 3]
> my_list.append(4)    # 添加元素 -> [10, 2, 3, 4]
> del my_list[1]       # 删除元素 -> [10, 3, 4]
>
> # 元组：不可变
> my_tuple = (1, 2, 3)
> # my_tuple[0] = 10   # 报错！TypeError: 'tuple' object does not support item assignment
> # my_tuple.append(4) # 报错！AttributeError: 'tuple' object has no attribute 'append'
> ```
>
> *注意：如果元组中包含可变对象（如列表），该可变对象内部依然是可以修改的，但这并不是修改元组本身的结构：*
>
> ```python
> t = (1, 2, [3, 4])
> t[2][0] = 'a'  # 这是合法的，因为修改的是列表，而不是元组的引用
> print(t)       # 输出: (1, 2, ['a', 4])
> ```
>
> ### 2. 语法表示
> *   **列表：** 使用方括号 `[]` 表示。
> *   **元组：** 使用圆括号 `()` 表示。
>
> *特殊规则：* 如果要创建只有一个元素的元组，必须在元素后面加逗号，否则 Python 会将其视为普通变量，而不是元组。
>
> ### 3. 内存占用与性能
> *   **内存占用：** 由于列表是可变的，Python 在底层为列表进行了过度分配，预留了额外的内存空间，以便在添加新元素时不需要每次都重新分配内存。因此，同等元素的列表比元组占用的内存更大。
> *   **创建速度：** 元组的创建速度通常比列表快，因为它的底层大小是固定的，不需要像列表那样动态调整内存。
> *   **访问速度：** 两者的访问速度差不多，但元组由于不可变，在解释器级别有时会被略微优化。
>
> ### 4. 方法和操作
> *   **列表：** 拥有丰富的方法，如 `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()` 等。
> *   **元组：** 因为不可变，所以没有修改元素的方法。元组只支持两个方法：`count()`（统计某元素出现次数）和 `index()`（查找元素的索引）。
>
> ### 5. 哈希性与字典键
> *   **列表：** 不可哈希，因此**不能**作为字典的键，也不能作为集合的元素。
> *   **元组：** 只要元组内的所有元素都是不可变类型，元组就是可哈希的，因此**可以**作为字典的键，也可以作为集合的元素。
>
> ### 6. 语义上的约定
> 在 Python 编程规范中，两者在语义上通常有不同的含义：
> *   **列表：** 通常用于存储同质数据，且数据长度在程序运行期间可能会发生变化。例如：一个购物车里的商品列表、一个动态获取的用户列表。
> *   **元组：** 通常用于存储异质数据，代表一个固定的数据结构整体（类似于数据库的一行记录）。例如：一个用户的个人信息 `("张三", 25, "male")`，或者表示一个固定的坐标 `(x, y)`。元组通常起到"结构体"的作用。
>
> ### 总结对比表
>
> | 特性 | 列表 | 元组 |
> | :--- | :--- | :--- |
> | **可变性** | 可变 | 不可变 |
> | **语法** | 方括号 `[]` | 圆括号 `()` |
> | **内存占用** | 较大（预留空间） | 较小（紧凑） |
> | **创建速度** | 较慢 | 较快 |
> | **方法数量** | 多 (`append`, `pop` 等) | 少 (`count`, `index`) |
> | **可哈希性** | 不可哈希 | 可哈希（如果元素均可哈希） |
> | **作为字典键** | 不可以 | 可以 |
> | **典型用途** | 动态数据的容器，同质数据集合 | 固定数据的记录，异质数据集合 |
>
> ### 什么时候用哪个？
> *   **用列表：** 当你需要对数据进行增、删、改操作时；当数据长度不确定时。
> *   **用元组：** 当数据一旦创建就不应该被修改时（保护数据完整性）；当你需要把数据作为字典的键时；当函数需要返回多个值时（Python 函数默认返回的就是元组）。
