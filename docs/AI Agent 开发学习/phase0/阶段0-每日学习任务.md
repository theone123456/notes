## 第 1 周：跑通第一个调用

### Day 1 · 环境准备与初识 LLM（约 1h）

- 确认 Python 3.10+，创建学习专用虚拟环境，安装 `openai` SDK
- 注册 DeepSeek（或通义）账号，获取 API Key，充值最小额度，了解计费规则
- 把 AI 当导师，问 3 个基础问题："大语言模型是怎么生成文字的"、"它和传统软件有什么区别"

- [x] ✅ 完成标志：终端能 `import openai` 成功，拿到可用的 API Key

### Day 2 · 第一次 API 调用（约 1h）

- 阅读 Chat Completions API 文档的快速上手部分
- 写第一个脚本：发送一条消息，打印模型回复
- 修改 system prompt（如"你是一个毒舌助手"），观察行为变化

- [x] ✅ 完成标志：跑通第一个对话脚本，能说出 system prompt 的作用

### Day 3 · 消息角色与多轮对话（约 1h）

- 理解 `system / user / assistant` 三种角色的分工
- **手动**构造 `messages` 数组实现两轮以上对话（不用任何封装）
- 对比实验：不带历史 vs 带历史提问"我刚才说了什么"

- [x] ✅ 完成标志：能解释为什么每次请求都要传完整历史

### Day 4 · Token 与上下文窗口（约 1h）

- 概念：tokenizer、按 token 计费、上下文窗口上限
- 实验：用响应中的 `usage` 字段，分别统计英文、中文、代码各 100 字的 token 消耗
- 思考：为什么中文更"贵"？超长对话会怎样？

- [x] ✅ 完成标志：能估算一段中文文本的大致 token 数

### Day 5 · 核心参数实验（约 1.5h）

- 学习 `temperature`、`top_p`、`max_tokens` 的含义
- 实验 1：同一问题，temperature 取 0 / 1.0 / 2.0 各问 3 次，对比输出稳定性
- 实验 2：故意调小 max_tokens，观察截断效果

- [x] ✅ 完成标志：留下一份简短的参数实验记录（哪种场景该用什么值）

### Day 6 · 幻觉与模型格局（约 1h）

- 概念：幻觉的成因（概率预测本质、训练数据截止时间）
- 实验：故意问一个冷门/虚构问题，诱导并观察幻觉
- 了解：主流模型格局（GPT/Claude/Gemini、DeepSeek/Qwen/GLM）、各自价格档位

- [x] ✅ 完成标志：能说出至少 2 种缓解幻觉的思路

### Day 7 · 周复盘 + 项目起步（约 1h）

- 复盘本周概念，把没搞懂的列成清单逐个问 AI
- 搭建 `LLMClient` 骨架：`__init__` 读取 Key、基础 `chat` 方法

- [x] ✅ 完成标志：`LLMClient` 能完成单轮对话

## 第 2 周：完成阶段产出

### Day 8 · 多轮对话 + 历史持久化（约 1.5h）

- 在类内部自动维护 `messages` 历史
- 实现 `save` / `load`：历史存为 JSON，可退出后恢复继续聊

- [x] ✅ 完成标志：中断程序后能加载历史接着聊

### Day 9 · 异常处理与重试（约 1h）

- 认识常见错误：超时、rate limit、无效 Key、余额不足
- 用 `try/except` + 简单重试逻辑包装请求（暂不引第三方库）

- [x] ✅ 完成标志：填错 Key 时程序不崩溃，报错信息清晰

### Day 10 · Token 统计与成本估算（约 1h）

- 累计每次调用的 `usage`（prompt / completion tokens）
- 按模型单价加一个成本估算方法

- [x] ✅ 完成标志：会话结束能打印总 token 数和估算费用

### Day 11 · 命令行聊天界面（约 1h）

- 用 `while` + `input()` 做命令行聊天，支持 `exit` 退出、`clear` 清空历史
- 实际多轮使用，体验记忆效果

- [x] ✅ 完成标志：一个完整可用的命令行聊天程序

### Day 12 · 代码整理与 Git（约 1h）

- 重构：拆分文件、补关键注释
- 写 README：功能、用法、参数说明
- `git init` 并提交（养成习惯，为求职项目铺路）

- [x] ✅ 完成标志：本地仓库建立，有规范的首次提交

### Day 13 · 概念查漏（约 1h）

- 扫尾了解级知识：预训练 / 微调 / 对齐三阶段各做什么

- [x] ✅ 完成标志：自测全部通过
