### Step 1 · 幻觉的定义与本质（类型：概念）

**前置依赖**：Day 5 的 temperature 概念（理解概率采样是理解幻觉的基础）

**做什么**：
- 学习幻觉（hallucination）的定义：模型生成看似合理但实际不正确、无依据或虚构的内容
- 理解幻觉与"说谎"的本质区别：模型没有"说谎"的意图，它只是在做概率预测，没有"知识验证"能力
- 建立直觉：LLM 本质是"概率接龙机器"--基于上文预测下一个 token，不具备"知道自己知道什么"的能力

**参考资料**：
- 可问 AI："什么是大语言模型的幻觉？它和人类说谎有什么区别？"
- 可问 AI："为什么说 LLM 是概率接龙机器？这跟幻觉有什么关系？"

- 能用一句话定义什么是幻觉
- 能说出幻觉和"说谎"的本质区别
- 能解释"LLM 是概率接龙机器"这个比喻的含义

### Step 2 · 幻觉的成因（类型：概念）

**前置依赖**：Step 1 的幻觉定义与概率预测本质

**做什么**：
- 学习幻觉的核心成因 -- **概率预测本质**：模型不"知道"事实，只预测最可能的下一个 token，当概率最高的 token 恰好不是事实时就产生幻觉
- 学习**训练数据截止时间**：模型知识有训练时的时效边界，训练截止后的新事件模型不可能知道，但可能"猜"一个看似合理的答案
- 了解**训练数据质量问题**：训练数据中的错误信息、偏见、噪声都可能被模型"学到"并复现
- 了解其他因素：**长尾知识**（冷门领域训练数据少，模型先验弱，更容易编造）/ **prompt 措辞引导**（如"请详细介绍"暗示模型"你应该知道"，诱发编造）

**参考资料**：
- 可问 AI："幻觉的具体成因有哪些？分别举例说明"
- 可问 AI："训练数据截止时间是怎么导致幻觉的？举一个实际例子"
- 可问 AI："为什么冷门问题更容易引发幻觉？"

**检查点**：
- 能说出至少 3 种幻觉的成因
- 能用"概率预测"解释幻觉为什么不可避免
- 能举例说明训练数据截止时间导致的幻觉

**产出**：
- 笔记：记入 readme.md 的幻觉成因节

### Step 3 · 诱导并观察幻觉（类型：实验）

**前置依赖**：Step 1 和 Step 2 的幻觉概念

**做什么**：
- 写脚本 `hallucination_experiment.py`
- 设计 3 类诱导幻觉的问题，每类至少 1 个：
  1. **虚构实体**：问一个不存在的人物/书籍/电影/论文（如"介绍一下 2023 年诺贝尔文学奖得主张三的代表作"）
  2. **冷门知识**：问一个非常冷门的问题，模型训练数据可能不足
  3. **过时信息**：问一个训练截止后发生变化的事实（如某公司现任 CEO、某国最新政策）
- 每次记录：问题类型、问题内容、模型回复、幻觉现象（编造细节 / 张冠李戴 / 自信陈述虚构信息 / 承认不知道）
- 观察要点：模型对虚构问题是自信编造还是承认不知道？幻觉内容的"合理程度"如何？
- 可选对比实验：加 system prompt "如果你不确定，请直接说不知道"，观察幻觉是否减少

**检查点**：
- 能观察到模型在虚构问题上产生幻觉（编造不存在的细节）
- 能区分不同类型的幻觉表现（编造实体 vs 张冠李戴 vs 过时信息）
- 能描述模型幻觉时的"自信"特征（不标注不确定性，像陈述事实一样编造）

**产出**：
- 文件：`hallucination_experiment.py`（自写，写完贴给 AI review）
- 实验数据：记入 readme.md 的实验记录节

### Step 4 · 缓解幻觉的思路（类型：思考）

**前置依赖**：Step 1-3 的概念和实验数据

**做什么**：
- 结合幻觉成因和实验观察，整理缓解幻觉的思路，至少覆盖以下方向：
  1. **提示词约束**：system prompt 要求"不知道就说不知道"（对应 Step 3 的可选对比实验）
  2. **降低 temperature**：减少低概率 token 被选中的机会（关联 Day 5 的 temperature 知识）
  3. **RAG（检索增强）**：给模型提供外部知识，让它"查资料"而非"猜"（对应训练数据截止和长尾知识两个成因）
  4. **结构化输出**：要求模型给出引用来源或置信度标记
  5. **多次采样投票**：同一问题问多次，取多数一致答案（代价是成本翻倍）
- 将每种缓解思路与具体成因对应（成因 -> 缓解手段），理解"对症下药"
- 思考：为什么 RAG 被认为是缓解幻觉最有效的手段之一？
- 将缓解思路和成因对应表写入 readme.md

**检查点**：
- 能说出至少 2 种缓解幻觉的思路（**本日完成标志**）
- 能将每种缓解思路对应到具体的幻觉成因
- 能用一句话解释"为什么 RAG 比单纯调低 temperature 更能缓解幻觉"

**产出**：

### Step 5 · 主流模型格局（类型：概念）

**前置依赖**：无（独立知识点）

**做什么**：
- 了解主流模型格局，分国际和国内两阵营：
  - **国际三强**：GPT（OpenAI）、Claude（Anthropic）、Gemini（Google）
  - **国内三强**：DeepSeek、Qwen（通义千问，阿里）、GLM（智谱）
- 了解各自的特点和定位：
  - GPT：综合能力标杆，生态最成熟，价格较高
  - Claude：长文本和推理强，安全对齐突出
  - Gemini：多模态能力突出，Google 生态
  - DeepSeek：性价比极高，代码 / 推理能力强
  - Qwen：开源生态好，中文能力强
  - GLM：国内生态成熟，推理模型表现好
- 了解价格档位的大致分层：高（GPT / Claude 旗舰）/ 中（DeepSeek / Qwen / GLM 旗舰）/ 低（各家精简版）
- 思考选型维度：成本、能力、中文支持、隐私合规、API 兼容性

**参考资料**：
- 可问 AI："目前主流的大语言模型有哪些？国际和国内分别是哪些？各自的特点是什么？"
- 可问 AI："这些模型的价格档位大概是怎么分的？"
- 可搜索各模型厂商官网的定价页面（了解级，不需要精确到每百万 token 多少钱）

**检查点**：
