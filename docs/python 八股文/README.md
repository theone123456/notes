# Python 社招测开面试学习计划

> 目标：社招测试开发岗（30K+ 方向）的 Python 面试准备。考察方式 = **语言八股 + 现场手写代码 + 结合测试场景的追问**。
>
> 与 `Test/pytest/plan/`（pytest 专项）互补：那套解决"框架与工具"，本套解决"Python 语言功底 + 网络数据库基础"。

## 一、面试官实际怎么考 Python（计划依据）

| 考察层次 | 占比 | 典型形式 | 对应准备 |
|---|---|---|---|
| 语言八股 | 约 35% | 可变/不可变、深浅拷贝、GIL、装饰器原理、垃圾回收 | `01`~`04` 文档 + `06` 速查 |
| 手写代码 | 约 35% | 装饰器/单例/LRU/生产者消费者 + 算法题（LeetCode 简单~中等） | `05` 文档 + `../hot_100/` |
| 场景结合 | 约 30% | 怎么 mock 依赖、怎么做并发压测脚本、SQL 注入怎么防、时间复杂度 | `03`/`04` 文档 |

**测开面试的 Python 特点**：不考偏难怪的语言细节，重点是**原理说得清 + 代码默写得出来**，并且能把语言特性落到测试场景（装饰器做重试、多线程做压测、生成器读大日志）。

## 三、7 天学习计划

### Day 1 -- 数据类型与函数（01 文档上半）

**学习**：可变/不可变、可变默认参数陷阱、深浅拷贝、is vs ==、参数传递、闭包、推导式。

**实践**：
- 把 01 文档每个"陷阱代码"在解释器里跑一遍，记录输出再对照答案
- 手写：闭包延迟绑定题、可变默认参数的修复版本

**自测**：
- [ ] 函数参数是值传递还是引用传递？能举例说明
- [ ] 浅拷贝和深拷贝的区别？切片是哪种？
- [ ] 闭包延迟绑定题为什么输出 [2,2,2]？怎么修？

### Day 2 -- 装饰器、生成器与 OOP（01 文档下半）

**学习**：装饰器（原理/wraps/带参）、迭代器协议、yield、OOP 全套（new vs init、MRO、三种方法、魔法方法）。

**实践**：
- **脱稿手写**：基础装饰器、带参数装饰器、__new__ 单例
- 写一个类实现 __enter__/__exit__，体验 with 语句

**自测**：
- [ ] `@deco` 语法糖等价于什么？wraps 不加会怎样？
- [ ] super() 是调用父类吗？D(B,C) 的 MRO 顺序？
- [ ] __str__ 和 __repr__ 的区别？

### Day 3 -- GIL 与并发编程（02 文档，测开分水岭）

**学习**：GIL 原理与影响、垃圾回收三件套、进程/线程/协程对比、锁、线程池。

**实践**：
- 写脚本对比：CPU 密集任务用多线程 vs 多进程的耗时
- 手写：生产者消费者、线程安全的单例

**自测**：
- [ ] GIL 是什么？为什么多线程跑不满多核？什么场景多线程仍然有效？
- [ ] 引用计数有什么缺陷？怎么解决？
- [ ] IO 密集和 CPU 密集分别选什么方案？

### Day 4 -- 标准库与工程实践（03 文档）

**学习**：collections、functools、异常体系、文件 IO、json、logging、mock。

**实践**：
- 用 Counter 统计一段日志中 IP 出现频率（Top10）
- 用 patch mock 掉 requests.get 并断言调用参数
- 配置一个按大小轮转的 logging

**自测**：
- [ ] try/except/else/finally 的执行顺序？
- [ ] pickle 和 json 的区别？
- [ ] patch 的目标路径怎么写？"where it's looked up"原则？

### Day 5 -- 网络与数据库（04 文档上半）

**学习**：TCP/UDP、三次握手四次挥手、HTTP 状态码与方法、requests 深入、SQL 手写题、索引、事务、SQL 注入。

**实践**：
- 手写 3 道 SQL：join 查询、group by 统计、第 N 高
- 写脚本：requests + HTTPAdapter 网络重试 + 超时元组
- 用 pymysql 演示参数化查询

**自测**：
- [ ] 401 和 403 的区别？502 和 504 的区别？
- [ ] 为什么用 B+ 树？什么情况索引失效？
- [ ] SQL 注入怎么防？为什么参数化有效？

### Day 6 -- 设计模式与手写题（04 文档下半 + 05 全部）

**学习**：单例（3 种）、工厂、PO 模式；05 文档 22 道手写题。

**实践**：
- **脱稿默写**：重试装饰器、LRU、生产者消费者、二分查找、快排
- 算法：继续刷 hot_100（每天 2-3 题，重点：字符串/哈希/双指针/滑窗）

**自测**：
- [ ] 单例的线程安全版怎么写（双重检查锁）？
- [ ] LRU 的 get/put 各做什么操作？复杂度？
- [ ] 能 10 分钟内默写出快排和二分？

### Day 7 -- 八股速查背诵 + 模拟面试

**背诵**：`06文档` 90+ 问，按主题过 3 遍：第一遍理解、第二遍记关键词、第三遍合上文档复述。

**模拟面试**：
- 自问自答：随机抽 15 题，每题 1 分钟作答并录音回听
- 手写题限时演练：05 文档随机抽 5 题，每题 10 分钟白板/纸写
- 结合简历项目准备 3 个"Python 特性落地测试场景"的故事（重试装饰器、多线程压测、生成器处理大日志）

## 四、方法论

1. **每个知识点必须跑代码验证**，尤其"陷阱题"（可变默认参数、闭包延迟绑定、浅拷贝共享）
2. 手写题标准：**脱稿 + 10 分钟内 + 无语法错误**，达不到就重复写
3. 八股答案先理解原理再背关键词，面试官追问"为什么"时能下钻一层
4. 每天收尾 3 行总结：记住了什么 / 没记住什么 / 明天补什么
