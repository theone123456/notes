# 常用标准库与工程实践

> 测开面试最爱考"你平时用哪些标准库"，本文档每个库都要能说出 1-2 个测试场景应用。

## 一、collections（必会）

```python
from collections import Counter, defaultdict, deque, OrderedDict, namedtuple

# Counter：计数器，统计频率首选
logs = ['1.1.1.1', '2.2.2.2', '1.1.1.1']
top_ip = Counter(logs).most_common(2)          # [('1.1.1.1', 2), ('2.2.2.2', 1)]

# defaultdict：取不存在的键不报错，自动给默认值
groups = defaultdict(list)
for name, dept in [('a', 'qa'), ('b', 'dev')]:
    groups[dept].append(name)                  # {'qa': ['a'], 'dev': ['b']}

# deque：双端队列，两端操作 O(1)
dq = deque([1, 2, 3], maxlen=5)                # maxlen 满后自动挤掉另一端
dq.appendleft(0); dq.pop()                     # 滑动窗口/任务队列

# OrderedDict：有序字典（LRU 实现核心：move_to_end + popitem(last=False)）
# namedtuple：轻量不可变记录
Point = namedtuple('Point', ['x', 'y'])
```

测开场景：Counter 统计日志高频错误 / defaultdict 按模块归组用例 / deque 实现滑动窗口限流。

## 二、functools

```python
from functools import lru_cache, wraps, partial, reduce

@lru_cache(maxsize=128)        # 缓存结果，递归优化神器（斐波那契从 O(2^n) -> O(n)）
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

int2str = partial(int, base=2)  # 固定部分参数
reduce(lambda a, b: a * b, [1, 2, 3, 4])   # 24，累积计算
```

- `lru_cache` 原理：字典 + 双向链表实现的 LRU；参数必须可哈希
- `wraps`：装饰器标配，保留原函数元信息

## 三、itertools

```python
from itertools import chain, product, groupby, islice

chain([1, 2], [3, 4])                    # 拼接多个可迭代对象
```

## 四、异常处理（必考）

### 1. 完整语法与执行顺序

```python
try:
    risk()
except (ValueError, KeyError) as e:      # 多种异常可合并捕获
    handle(e)
except Exception as e:                   # 子类异常必须写在父类前面
    handle_all(e)
else:
    print('try 没抛异常才执行')           # else 在 try 成功后执行
finally:
    cleanup()                            # 无论如何都执行（except 里 return 也执行）
```

**执行顺序**：try -> （异常时）匹配 except -> else（无异常时）-> finally。

### 2. 经典坑：finally 里的 return 会吞掉异常

```python
def bad():
    try:
        raise ValueError('boom')
    finally:
        return 'ok'        # 异常被静默吞掉！finally 的 return 覆盖一切
```

### 3. 自定义异常（测试框架常用）

```python
class ApiTestError(Exception):
    def __init__(self, code, message):
        self.code = code
        super().__init__(f'[{code}] {message}')

raise ApiTestError(500, '服务端错误')
```

### 4. 其他要点

- 异常层次：`BaseException`（含 KeyboardInterrupt/SystemExit）-> `Exception` -> 具体异常；业务捕获用 Exception，不要捕 BaseException
- `raise` 裸写：在 except 内原样重抛；`raise NewErr from e` 保留异常链
- `traceback.format_exc()` 拿完整堆栈字符串（写日志用）
- EAFP vs LBYL：Python 风格偏好 EAFP（先做，出错再处理），如 dict.get / try 捕获 KeyError

## 五、文件与 IO

### 1. with 语句原理（必考）

`with` 调用对象的 `__enter__`（进入）和 `__exit__`（退出，**即使抛异常也会执行**），是 try/finally 的语法糖。

```python
class Timer:
    def __enter__(self):
        self.start = time.time()
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f'耗时 {time.time() - self.start:.3f}s')
        return False      # False=异常继续向外抛，True=吞掉异常

with Timer():
    do_work()
```

`contextlib.contextmanager` + 生成器可快速实现（见 05 文档）。

### 2. 文件操作要点

- 模式：`r` 读 / `w` 清空写 / `a` 追加 / `rb`/`wb` 二进制 / `+` 读写
- **必须指定 encoding**：`open(p, encoding='utf-8')`，Windows 默认 gbk 是乱码之源
- 大文件**禁止** `f.read()`/`f.readlines()` 一次性载入；直接迭代文件对象逐行读（惰性）
- `pathlib.Path` 优于 os.path：`Path('logs') / 'a.log'`、`.exists()`、`.glob('*.py')`

### 3. json（测开高频）

```python
import json

json.dumps(obj, ensure_ascii=False, indent=2)   # 序列化为字符串，中文不转义
json.loads(s)                                    # 反序列化
json.dump(obj, f) / json.load(f)                 # 直接与文件交互

# 对象里有 datetime 等不支持的类型：
json.dumps(obj, default=str)                     # default: 遇到无法序列化的对象时调用
```

### 4. pickle vs json（必考）

| | json | pickle |
|---|---|---|
| 格式 | 文本，跨语言 | 二进制，仅 Python |
| 支持类型 | 基础类型 | 几乎所有 Python 对象（含类实例） |
| 安全性 | 安全 | **不安全**：反序列化可执行任意代码，禁止 load 不可信数据 |
| 场景 | 接口、配置 | Python 内部缓存/深拷贝辅助 |

## 六、logging（测开必会）

四大组件：Logger（入口）-> Handler（输出到哪里）-> Formatter（格式）-> Filter（过滤）。

```python
import logging
from logging.handlers import RotatingFileHandler

logger = logging.getLogger('api_test')
logger.setLevel(logging.DEBUG)

fmt = logging.Formatter('%(asctime)s [%(levelname)s] %(name)s - %(message)s')

console = logging.StreamHandler()
console.setFormatter(fmt)
logger.addHandler(console)

file_handler = RotatingFileHandler(
    'app.log', maxBytes=10 * 1024 * 1024, backupCount=5, encoding='utf-8')
file_handler.setFormatter(fmt)
logger.addHandler(file_handler)

logger.info('请求 %s 完成，状态码 %s', url, status)   # 惰性格式化，推荐占位符而非 f-string
```

**经典坑**：重复调用配置导致日志重复打印 -> 因为 handler 被重复 add。防御写法：`if not logger.handlers:` 再添加（或只配置根 logger 一次）。级别从低到高：DEBUG < INFO < WARNING < ERROR < CRITICAL。

## 七、mock（测开专属必考）

```python
from unittest.mock import patch, Mock, MagicMock

# 1. patch 的目标是【被使用的位置】，不是【定义的位置】！
#    my_mod.py 里 import requests 后调用 requests.get
#    -> patch('my_mod.requests.get') 正确；patch('requests.get') 错误（除非直接 patch 模块属性使用处）

# 写法一：装饰器
@patch('my_mod.requests.get')
def test_api(mock_get):
    mock_get.return_value.status_code = 200
    mock_get.return_value.json.return_value = {'code': 0}
    assert my_mod.call_api() == 0
    mock_get.assert_called_once_with('http://x')      # 断言调用参数

# 写法二：上下文管理器
with patch('my_mod.requests.get') as mock_get:
    ...

# side_effect：连续返回不同值 / 抛异常 / 调用真实函数
mock_get.side_effect = [resp1, resp2]                 # 依次返回
mock_get.side_effect = ConnectionError('timeout')     # 模拟异常
mock_get.side_effect = real_func                      # 透传调用真实现
```

- `Mock` vs `MagicMock`：MagicMock 支持魔法方法（`__len__`、`__iter__` 等），默认用 MagicMock
- `return_value` vs `side_effect`：固定返回 vs 动态行为
- 与 pytest 的 `monkeypatch` 对比：monkeypatch 测试结束自动还原、API 更简单；mock 断言能力强（断言被怎么调用）

## 八、其他高频标准库

### 1. re 正则

```python
import re
re.match(r'\d+', '123abc')        # 从头匹配，失败返回 None
re.search(r'\d+', 'abc123')       # 全串搜索第一个
re.findall(r'\d+', 'a1b22c333')   # ['1', '22', '333']
re.sub(r'\s+', ' ', s)            # 替换
m = re.search(r'(\d+)-(\d+)', s); m.group(1)   # 分组
r'<(\w+)>.*?</\1>'                # 反向引用 + 非贪婪（.+ 尽可能多，.+? 尽可能少）
```

match vs search：**match 只认开头**（必考）。

### 2. time / datetime

```python
from datetime import datetime, timedelta

datetime.now().strftime('%Y-%m-%d %H:%M:%S')
datetime.strptime('2026-08-31', '%Y-%m-%d')
datetime.fromtimestamp(ts) / dt.timestamp()
(datetime.now() - timedelta(days=7)).isoformat()   # 一周前
```

### 3. hashlib / base64

```python
import hashlib
hashlib.md5('abc'.encode()).hexdigest()         # 32 位（已不安全，仅校验用）

import base64
base64.b64encode(s.encode()).decode()           # 编码不是加密！可逆
```

### 4. random（造测试数据）

`random.randint(a, b)` / `random.choice(seq)` / `random.sample(seq, k)` / `random.shuffle(lst)`；造随机手机号、随机用户名。

## 九、类型注解与工程化

```python
from typing import Optional, Union, Callable, Any
def fetch(url: str, retry: int = 3, timeout: Optional[float] = None) -> dict: ...
```

- 注解不强制执行（运行时不检查），价值：可读性 + IDE 提示 + mypy 静态检查
- 3.9+ 可直接用 `list[str]`、`dict[str, int]`

**工程化要点**：
- PEP8 核心记住：4 空格缩进、蛇形命名函数/变量、大驼峰类名、行宽 79/99、导入顺序（标准库->第三方->本地）
- 依赖管理：venv 虚拟环境隔离、requirements.txt 固定版本、`pip freeze > requirements.txt`、了解 uv/poetry
- `if __name__ == '__main__'`：模块被直接运行时才执行，被 import 时不执行
