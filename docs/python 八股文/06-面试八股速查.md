# Python 面试八股速查（背诵版）

> 共 90 问，按主题分组。每题答案是"关键词式"展开的口播版：先给结论，再补一句解释。
> 用法：第一遍对照 `01`~`04` 文档理解；第二遍只看题目回忆关键词；第三遍合上文档自问自答。

## A. 基础语法（15 问）

**1. Python 有哪些可变/不可变类型？**
可变：list、dict、set、bytearray；不可变：int、float、bool、str、tuple、frozenset、bytes。

**2. 函数参数是值传递还是引用传递？**
传对象引用（shared reference）。可变对象被原地修改会影响外部；不可变对象重新赋值只改本地绑定。

**3. 可变默认参数的坑？**
默认值在函数定义时求值一次并被所有调用共享。修复：默认 None，函数体内判断后新建。

**4. 深拷贝和浅拷贝的区别？**
浅拷贝只复制最外层容器，内部子对象仍共享引用；深拷贝递归复制所有层级。切片、list()、dict()、copy() 都是浅拷贝。

**5. is 和 == 的区别？**
== 比较值（__eq__），is 比较对象身份（id 是否相同）。判断 None 必须用 is。

**6. 小整数缓存和字符串驻留？**
[-5, 256] 的整数是全局共享的同一对象；编译期确定的字符串常量会被驻留复用。所以该范围内 is 返回 True，这是实现细节不应依赖。

**7. list 和 tuple 的区别？**
可变 vs 不可变；tuple 可哈希能作字典键、内存更小；tuple 适合固定结构，list 适合会变的数据。

**8. dict 的键有什么要求？**
必须可哈希（不可变类型）。可变对象没有稳定哈希值，会破坏哈希表定位。

**9. dict 是有序的吗？查找复杂度？**
3.7 起保证插入有序；哈希表实现，查找/插入/删除平均 O(1)。

**10. 集合支持哪些运算？**
& 交集、| 并集、- 差集、^ 对称差；set 自动去重、成员判断 O(1)。

**11. 字符串大量拼接为什么用 join？**
str 不可变，+ 循环拼接每次都创建新串，O(n²)；join 一次分配 O(n)。

**12. LEGB 是什么？**
变量查找顺序：Local -> Enclosing（闭包外层）-> Global（模块级）-> Built-in。

**13. global 和 nonlocal 的区别？**
global 声明使用全局变量；nonlocal 声明使用闭包外层函数的变量（用于内层函数改外层值）。

**14. *args 和 **kwargs 是什么？**
*args 收集多余位置参数为元组；**kwargs 收集多余关键字参数为字典。调用侧 * / ** 是解包。

**15. 什么是一等函数？**
函数是对象：可赋值给变量、作为参数传递、作为返回值、存进容器。这是装饰器、高阶函数的基础。

## B. 函数与装饰器（10 问）

**16. 装饰器原理？**
@deco 等价于 func = deco(func)，装饰器接收函数返回新函数，在调用前后加逻辑。

**17. functools.wraps 的作用？**
把原函数的 __name__、__doc__ 等元信息复制到 wrapper，否则调试和反射看到的都是 wrapper。

**18. 带参数装饰器为什么是三层？**
外层接收装饰器参数 -> 中层接收被装饰函数 -> 内层执行逻辑并透传参数。@retry(times=3) 先执行 retry(times=3) 得到真正的装饰器。

**19. 闭包是什么？**
内层函数引用外层函数的变量且被传出，外层变量生命周期被延长。用途：装饰器、工厂函数。

**20. 闭包延迟绑定问题？**
列表推导式里的 lambda 共享同一个循环变量 i，循环结束 i 才定值，所以全是最后一个值。修复：默认参数 i=i 在定义时固化。

**21. 迭代器和可迭代对象的区别？**
可迭代对象实现 __iter__；迭代器额外实现 __next__。iter() 把可迭代对象变成迭代器，for 循环自动做这件事。

**22. 生成器是什么？yield 做了什么？**
含 yield 的函数，调用不执行只返回生成器对象。yield 暂停函数并保存现场，下次 next 从暂停点继续。

**23. 生成器的优势？能遍历几次？**
惰性求值、内存 O(1)，适合大文件、无限序列；只能遍历一次，耗尽即抛 StopIteration。

**24. 生成器表达式和列表推导式的区别？**
(...) 惰性返回生成器，[...] 立即构建完整列表占内存。

**25. range 是生成器吗？**
不是，是惰性可重复迭代的 range 对象（支持 len、切片、多次遍历）。

## C. 面向对象（12 问）

**26. __new__ 和 __init__ 的区别？**
__new__ 创建实例（静态方法，返回实例），__init__ 初始化实例（不返回值）。单例用 __new__ 实现。

**27. 实例方法、类方法、静态方法的区别？**
首参分别是 self/cls/无；类方法用 @classmethod 常做工厂方法，静态方法 @staticmethod 是挂在类里的工具函数。

**28. 属性查找顺序？**
实例 __dict__ -> 类属性 -> 沿 MRO 找父类。

**29. super() 是调用父类吗？**
不是，是调用 MRO 中的下一个类。多继承下保证每个类只被初始化一次。

**30. MRO 是什么？菱形继承下输出什么？**
方法解析顺序，C3 线性化。D(B,C) 继承 A：D -> B -> C -> A，A 只执行一次。

**31. Python 怎么实现多态？**
鸭子类型：不看继承类型，只要实现了同名方法就能替换使用，运行时动态绑定。

**32. __getattr__ 和 __getattribute__ 的区别？**
__getattr__ 只在常规查找失败后触发；__getattribute__ 每次属性访问都触发（内部必须 super() 否则无限递归）。

**33. __str__ 和 __repr__ 的区别？**
str 面向用户可读；repr 面向开发者、尽量可重建对象，交互式控制台显示的是 repr。

**34. with 语句的原理？**
调用 __enter__ 和 __exit__；__exit__ 即使抛异常也执行，实现安全释放资源。__exit__ 返回 True 会吞掉异常。

**35. Python 有真正的私有属性吗？**
没有。_x 是约定；__x 触发名称改写为 _ClassName__x，只是避免子类误覆盖。

**36. __slots__ 的作用？**
限定实例只能有哪些属性并省去 __dict__，省内存；代价是失去动态加属性的能力。

**37. 什么是元类？**
类的类（默认 type），控制类的创建过程。metaclass 参数指定，ORM 和单例的底层手段，能说出概念即可。

## D. 内存与并发（15 问）

**38. GIL 是什么？**
CPython 的全局解释器锁，同一时刻只允许一个线程执行字节码，导致多线程无法利用多核做 CPU 并行。

**39. 为什么需要 GIL？**
保护引用计数的线程安全（历史设计的最简方案），不是语言规范，Jython/IronPython 没有。

**40. 多线程什么时候仍然有效？**
IO 密集任务：阻塞 IO、sleep、C 扩展运算时会释放 GIL，其他线程可执行。

**41. CPU 密集和 IO 密集分别怎么选？**
CPU 密集用多进程（绕开 GIL 真并行）；IO 密集用多线程或协程（等待时可切换）。

**42. 有了 GIL 还要加锁吗？**
要。GIL 只保证单条字节码原子，i += 1 是加载/相加/存储三条字节码，多线程可能交错执行丢更新。

**43. Python 垃圾回收机制？**
以引用计数为主（归零即回收），辅以标记-清除解决循环引用，分代回收（0/1/2 三代，阈值 700/10/10）降低全量扫描开销。

**44. 引用计数的缺陷？**
维护计数有开销；无法回收循环引用；非线程安全需 GIL 保护。

**45. 什么是循环引用？怎么被回收？**
对象互相引用导致计数不归零；由标记-清除从根对象（GC roots）做可达性分析，清除不可达对象环。

**46. 怎么排查内存泄漏？**
tracemalloc 快照对比找增长对象、objgraph 看引用关系、gc.get_referrers 查引用者、sys.getsizeof 看大小。常见原因：全局缓存只增不减、闭包持有大对象、线程/定时器未释放。

**47. 进程和线程的区别？**
进程是资源分配单位（独立地址空间，隔离好、切换贵）；线程是调度执行单位（共享进程内存，切换便宜但需要锁）。进程通信靠 Queue/Pipe/共享内存，线程靠共享变量加锁。

**48. start() 和 run() 的区别？**
start() 新建线程并异步执行；run() 只是在当前线程同步调用方法，不创建线程。

**49. 守护线程是什么？**
daemon=True 的线程，主线程退出时被直接终止，适合心跳、后台采集等不需要收尾的任务。

**50. 死锁的四个必要条件？**
互斥、持有并等待、不可剥夺、循环等待。避免：统一加锁顺序、acquire(timeout=)、一次性申请全部锁。

**51. 协程和线程的区别？**
协程单线程内用户态调度，切换成本纳秒级、内存 KB 级、单机可十万级；线程由内核调度、微秒级、栈 MB 级。协程适合超高并发 IO，但要求全链路非阻塞。

**52. asyncio 的核心概念？**
事件循环调度协程；async def 定义协程，await 让出控制权等待结果；gather 并发执行多个任务。阻塞调用（requests/time.sleep）会卡死整个循环，要用 aiohttp/asyncio.sleep。

**53. 生产者消费者模型怎么实现？**
queue.Queue（线程安全自带锁）做缓冲，生产者 put、消费者 get，put(None) 作为结束信号，多消费者放对应数量的 None。

## E. 标准库与工程（10 问）

**54. try/except/else/finally 执行顺序？**
try -> 异常时匹配 except（子类在前）-> 无异常执行 else -> finally 必执行。

**55. finally 里 return 会怎样？**
会覆盖 try/except 的返回值并吞掉异常，属于反模式。

**56. 怎么自定义异常？**
继承 Exception（不要继承 BaseException），__init__ 里补充业务字段并 super().__init__(消息)。

**57. json 和 pickle 的区别？**
json 文本跨语言只支持基础类型且安全；pickle 二进制仅 Python 支持任意对象，反序列化可执行任意代码，不能加载不可信数据。

**58. json.dumps 处理 datetime？**
传 default=str（遇到不支持类型时的兜底函数）；反序列化用 object_hook 还原。

**59. logging 四大组件？日志重复打印怎么解决？**
Logger -> Handler -> Formatter -> Filter。重复打印是 handler 被重复 add，用 if not logger.handlers 保护或只配置一次。

**60. match 和 search 的区别？**
re.match 只从字符串开头匹配；re.search 扫描全串找第一个匹配。

**61. 贪婪与非贪婪匹配？**
默认 .* / .+ 尽可能多匹配（贪婪）；加 ? 变成 .*? 尽可能少（非贪婪），提取标签内容必备。

**62. patch 应该 patch 哪里？**
patch 使用处而非定义处：模块 A `import requests` 后用 `requests.get`，应 patch('A.requests.get')。

**63. return_value 和 side_effect 的区别？**
return_value 固定返回；side_effect 可依次返回序列、抛异常或代理真函数。

## F. 网络与数据库（18 问）

**64. TCP 和 UDP 的区别？**
TCP 面向连接、可靠有序（确认重传）、慢；UDP 无连接、尽力交付、快。HTTP 用 TCP，DNS 查询常用 UDP。

**65. 三次握手为什么是三次？**
双方都要确认收发能力正常；两次无法拒绝历史失效的 SYN 请求，会建立错误连接浪费资源。

**66. 四次挥手为什么是四次？**
被动方收到 FIN 时可能还有数据没发完，先 ACK、发完再 FIN，中间两步不能合并。主动方最后 TIME_WAIT 等 2MSL 确保对方收到 ACK。

**67. 401 和 403 的区别？**
401 未认证（没登录/token 无效）；403 已认证但无权限。

**68. 502 和 504 的区别？**
502 网关收到了后端的无效响应或连接被拒；504 后端在超时时间内没有返回。都是网关侧报错。

**69. GET 和 POST 的区别？**
GET 参数在 URL、幂等、可缓存；POST 在 body、非幂等。语义上 GET 获取资源、POST 提交数据。

**70. PUT 和 PATCH 的区别？**
PUT 全量替换（幂等）；PATCH 部分更新。

**71. Cookie、Session、Token 的区别？**
Cookie 客户端存储机制；Session 数据在服务端靠 sessionId 关联（有状态）；JWT 自包含签名在客户端（无状态、适合分布式、可注销是难题）。

**72. HTTPS 握手一句话？**
客户端验证服务端证书，非对称算法协商出对称密钥，之后用对称加密通信（非对称只用于交换密钥）。

**73. requests 的 json= 和 data= 的区别？**
json= 序列化为 JSON 体并设 Content-Type: application/json；data= 发表单（x-www-form-urlencoded）或原始字符串。

**74. requests 的 timeout 怎么用？**
timeout=5 连接和读取都是 5 秒；timeout=(3, 10) 分别指定连接 3 秒、读取 10 秒。不设则永久等待。

**75. requests 异常怎么统一捕获？**
Timeout 和 ConnectionError 都继承 RequestException，逐个细分捕获最后用 RequestException 兜底；resp.raise_for_status() 可把 4xx/5xx 转异常。

**76. WHERE 和 HAVING 的区别？**
WHERE 在分组前过滤行（不能用聚合函数）；HAVING 在分组后过滤组（可用聚合函数）。

**77. inner/left/right join 的区别？**
inner 只返回两表都匹配的行；left 保留左表全部（右表无匹配补 NULL）；right 反之。

**78. 为什么 MySQL 用 B+ 树？**
非叶子节点不存数据，单页放更多键，树矮 IO 少；叶子节点双向链表，范围查询和排序高效。哈希不支持范围，B 树数据分散导致树更高。

**79. 什么是回表和覆盖索引？**
二级索引叶子只存主键，查非索引列要回主键树再查一次（回表）；查询列全部包含在索引中则免回表（覆盖索引）。

**80. 联合索引最左前缀原则？**
(a,b,c) 索引只命中以 a 开头的查询条件；跳过 a 或对 a 用函数/范围后接列会失效。

**81. 事务隔离级别及默认值？**
读未提交/读已提交/可重复读/串行化；InnoDB 默认可重复读（MVCC + 间隙锁基本解决幻读）。脏读、不可重复读、幻读逐级消除。

**82. SQL 注入原理与防范？**
拼接 SQL 时用户输入被当作 SQL 语法的一部分（' OR '1'='1）。防范：参数化查询（execute(sql, params)），驱动把输入严格当数据；ORM、最小权限、输入校验辅助。

**83. 缓存穿透、击穿、雪崩？**
穿透=查不存在的 key 打穿到 DB（缓存空值/布隆过滤器）；击穿=单个热点 key 过期瞬间高并发打 DB（互斥锁/不过期）；雪崩=大量 key 同时过期或 Redis 宕机（随机 TTL/集群/限流）。

## G. 设计模式与测试开发场景（10 问）

**84. 单例模式有几种实现？**
__new__ 判断、装饰器闭包字典、元类 __call__、模块天然单例。多线程需双重检查锁。

**85. 单例的线程安全怎么保证？**
if None 的快速路径 + with Lock + 二次 if None（双重检查），保证只创建一次且无竞争后仍有性能。

**86. 工厂模式解决什么问题？**
把对象创建逻辑集中封装，调用方不依赖具体类；新增类型只改工厂（对扩展开放对修改关闭）。场景：按环境创建测试客户端。

**87. PO 模式的思想？**
页面/接口封装为对象，定位与操作内聚在 PO 类，用例只调方法。元素/接口变更只改 PO，用例零修改。

**88. 策略模式在测试中怎么用？**
把可互换的算法封装成独立类（不同重试策略、数据生成策略、断言策略），运行时按配置注入，避免 if-else 膨胀。

**89. 观察者模式在测试中怎么用？**
测试完成后通知所有订阅者（邮件、钉钉、企微、落库），新增通知渠道只需加订阅者，不改发布方。

**90. 描述你用 Python 解决过的测试问题（万能模板）**
问题（回归慢/偶发失败/排查难）-> 技术选型（装饰器/多线程/生成器/上下文管理器）-> 实现（一两句话）-> 量化收益（时间从 X 到 Y）。提前准备 3 个真实故事：重试装饰器消除偶发失败、线程池压测脚本、生成器处理大日志定位问题。
